# Arquitectura de Software

Principios, leyes y estructura que definen cómo se construyen los sistemas. Esto no es teoría abstracta — son decisiones concretas que podés aplicar hoy.

## Secciones

- **Leyes y Manifiesto** — Principios fundamentales que rigen el diseño
- **Granularidad y Empaquetado** — Cómo decidir el tamaño y distribución de componentes
- **Arquitectura Hexagonal** — Implementación práctica de puertos y adaptadores
- **Arquitectura de Juegos** — Patrones específicos para desarrollo de videojuegos
